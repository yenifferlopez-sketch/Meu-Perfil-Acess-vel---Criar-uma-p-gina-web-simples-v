# 👤 Meu Perfil Acessível

Página web desenvolvida para apresentar informações fictícias de um estudante de forma clara, organizada, responsiva e acessível.

## 📁 Estrutura do Projeto

- `index.html`: Estrutura semântica da página.
- `style.css`: Estilização, contraste, espaçamento e responsividade (`@media`).
- `README.md`: Documentação do projeto.

## ♿ Boas Práticas de Acessibilidade Aplicadas

- Textos curtos, diretos e fáceis de compreender.
- Hierarquia clara de títulos (`<h1>` e `<h2>`) e tags semânticas (`<header>`, `<main>`, `<section>`, `<footer>`).
- Tipografia legível (`Arial`) com tamanho de fonte confortável e bom espaçamento entre linhas.
- Alto contraste entre texto e fundo, utilizando uma paleta reduzida de cores.
- Imagem com descrição alternativa (`alt="Avatar do estudante"`).
- Botão com rótulo descritivo e indicador visual de foco (`:focus`).
